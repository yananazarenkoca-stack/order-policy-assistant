# order-policy-assistant

A small web app that answers customer questions about a fictional store's order policies

## Development

Requires Node 24 (`nvm use`).

```sh
npm install
npm run dev:server   # API on http://localhost:3001
npm run dev:web      # Vite dev server; proxies /api to the server
npm run lint         # ESLint
npm run format       # Prettier
npm run typecheck
npm run build
```
