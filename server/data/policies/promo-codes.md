# Promo Codes and Discounts

## Rules for promo codes

- **One promo code per order.** Promo codes can't be combined with each other.
- Promo codes **can** be combined with Trail Points redemptions and gift cards.
- Promo codes aren't valid on gift cards, preorders, or final sale items.
- We can't add a forgotten code after the order is placed. Within the 1-hour cancellation window, you can cancel and order again with the code.

## Welcome code

New customers get **WELCOME10**: 10% off the first order, up to **$50** off. It works once per customer and once per shipping address.

## How discounts are split across items

An order-level discount is spread across the eligible items **in proportion to their prices**. The amount assigned to each item is used for refunds and price adjustments.

## Returns from orders with a minimum-spend code

Some codes need a minimum spend (for example, **TRAIL20: $20 off orders of $150 or more**). If you return items and what you **keep** no longer meets the minimum, the discount is removed from the kept items and taken out of your refund.

**Example:** an order of $160 with TRAIL20 costs $140. You return a $30 item.

- The $30 item's share of the discount is $3.75, so you paid $26.25 for it.
- The kept items ($130) are now under $150, so their $16.25 share of the discount is removed.
- Refund: $26.25 − $16.25 = **$10.00**, before tax and the $8.95 return label fee.
