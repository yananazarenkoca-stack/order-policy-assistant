# Holiday Returns 2026

## Extended holiday return window

Items **ordered between November 15 and December 24, 2026** (inclusive) can be returned or exchanged until **January 31, 2027**, or within the standard 30 days from delivery, **whichever is later**.

The extended window also covers Black Friday Week (November 27 – December 1, 2026) purchases.

## What the holiday window doesn't change

- **Final sale items** still can't be returned.
- The **$8.95 return label fee** and **restocking fees** (15% opened electronics, 20% oversized) still apply.
- Trail Points still become available 14 days after delivery. If you spend them and then return the item, the Loyalty Points policy applies.

## Order date decides eligibility

The **order date** decides whether the holiday window applies, not the delivery date. This matters for preorders and backorders.

Example: a preorder placed October 20, 2026 and delivered December 5, 2026 does **not** get the holiday window. It can be returned until January 4, 2027 (30 days from delivery).

## International holiday returns

International holiday returns must be **postmarked by January 31, 2027**.

## Gift receipts

Gift recipients with a gift receipt can return items for **store credit** (an e-gift card in the recipient's name) without the buyer being notified. Gift-receipt returns can't be refunded to the original payment method.
