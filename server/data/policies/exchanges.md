# Exchanges Policy

## What can be exchanged

You can exchange an item for the **same product in a different size or colour** within the return window (30 days from delivery, or the holiday window if it applies). To switch to a different product, return the item for a refund and place a new order.

## Cost of an exchange

Exchanges are free within Canada. There's no return label fee, and the replacement ships free by standard shipping. If the new size or colour costs more, you pay the difference. If it costs less, we refund the difference to your original payment method.

## How exchanges work

Start an exchange from Account > Orders > Exchange item. We ship the replacement **as soon as the carrier scans your return package**, without waiting for it to reach our warehouse. If your return hasn't reached us within 21 days of the replacement shipping, we charge your card for the replacement.

## Limits on exchanges

- One exchange per item. A second exchange of the same item is handled as a return and a new order.
- If the replacement is out of stock, we refund the item instead, and the return label fee is still waived.
- **Final sale items can't be exchanged**, not even for a different size.
- Oversized items (kayaks, canoes, bikes, etc.) can't be exchanged.
- Exchanges aren't available on international orders. Return the item and place a new order instead.
